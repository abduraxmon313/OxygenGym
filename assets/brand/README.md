# Logo

Bu papkaga do'kon logosini (PNG, JPG yoki WEBP) bitta fayl qilib joylang. Fayl nomi muhim emas.

Har bir build'da `scripts/prepare-brand.py` shu rasmdan quyidagilarni yasaydi:

- yon menyudagi logo — asl rasm, o'zgartirishsiz;
- dastur va o'rnatuvchi ikonkasi (`assets/icon.png`, `assets/icon.ico`).

Logoni almashtirish uchun eski faylni o'chirib, yangisini qo'ying va `main` ga merge qiling.
